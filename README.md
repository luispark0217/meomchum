# 멈춤

배달앱을 여는 순간 멈추고, 참은 만큼 돈과 kg으로 돌려받는 절제 앱 프로토타입입니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 결과물
```

## Vercel 배포

1. 이 폴더를 GitHub 저장소에 올립니다.
2. vercel.com → Add New → Project → 저장소 선택.
3. Framework Preset이 **Vite**로 잡히면 그대로 Deploy (Build: `npm run build`, Output: `dist`).

## 화면

- **온보딩**: 멈출 행동, 위험한 시간, 대신할 행동(약속), 이번 달 목표, 체중
- **오늘**: 멈춘 날, 먹고 싶어요(SOS), 배달앱 체험, 아낀 돈·kcal·환산 kg, AI 전화, 실제 체중
- **멈춤 흐름**: 배달앱(체험) → 잠깐 → 알아차리기(어디·강도·이유) → 1분 호흡 + 내가 남긴 말 → 강도 다시 → 참음/바꿔 먹기/먹음
- **참았을 때**: kcal·돈·kg, 제휴 보상(예시), 이번 달 아낀 돈 vs 구독료, 멈춤 통장에 넣기
- **먹었을 때**: 혼내지 않음 → 30분 뒤 기대 vs 실제, 내 목소리 녹음(10초) → 다음 갈망 때 재생
- **기록**: 위험한 시간, 먹은 이유, 1분 뒤 갈망 감소율, 결산 카드(공유)
- **통장**: 모은 돈, 받은 보상, 플러스(환불 보장), 설정(목소리, 예시 데이터, 초기화)

## 프로토타입 범위

- 데이터는 브라우저(localStorage)에만 저장됩니다. 서버 없음.
- 배달앱 가로채기는 앱 안의 체험용 가게로 보여 줍니다. 실제 서비스에서는 iOS 스크린타임 API / Android 접근성 권한으로 구현합니다.
- AI 전화는 앱 안에서 체험합니다(브라우저 음성 합성). 실제 전화는 음성 AI + 통신 API가 필요합니다.
- 결제·이체·기프티콘은 화면만 있고 실제로 일어나지 않습니다.
- 음식별 칼로리·금액은 배달 1회 기준 추정치, kg은 7,700kcal = 1kg 단순 환산입니다.
